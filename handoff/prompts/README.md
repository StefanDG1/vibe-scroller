# Prompt registry

These templates are implementation inputs, not a replacement for code-enforced permissions. Version prompt text and its hash with every run. Keep source evidence and trusted task policy in separate message fields.

Use structured output schemas where supplied. Validate IDs and evidence in server code after schema validation. Bound model repair attempts and include them in the quote.

Do not store hidden chain-of-thought content. Store the output, concise reasons, sources, usage, prompt version, model version, and validation results.

The marketing template belongs to V2 and must not become an enabled V1 tool. The implementation prompt operates inside a sandbox; it cannot authorize publication by itself.
