# Atlas implementation contract

Mode: reference. October 9, 2026. The owner authorized implementation of the design plan after selecting the branching diagram and an expanded folder alternative.

## Confirmed direction

Tree is the default Library representation. Folders is an expanded alternative over the same authorized topic IDs, saved parents and exact evidence. The owner's subsequent exact hybrid and expanded Folders images supersede the original layout interpretation under [ADR 096](../adr/096-exact-hybrid-library-and-authored-filing.md). First entry exposes the overview with a current branch preview; later visits restore a branch only after the current authorized page returns it. Personal and Business filing categories are independent of access scopes. Empty filing controls are local templates with no evidence or grant. Legacy team libraries retain Workspace access.

Use cool light surfaces, navy text, teal selection, a restrained yellow Save action and the original Scroll artwork. Follow the device theme, with Device setting/Light/Dark controls in Account. The tree must show real branching connectors rather than a folder indentation disguised as a graph. Mobile order is Home, Library, Save, Projects, Account. Save opens the existing reviewed capture dialog and never selects a navigation destination.

## Screen and interaction contracts

- Library: compact connected category pairs lead to a four-card Tree insight tray and contextual More insights. Expanded Folders places filing controls beside Library and inline insight rows under their category. Both share current source inspection, version-bound category corrections and explicit next-page actions. Missing parents remain separate roots. Generic saved ancestors are returned only through currently permitted leaves; absent ancestors are never fabricated.
- Project links: one bounded current-topic lookup previews the first insight's recorded proposal; selecting another card filters the cached projection by exact source and insight IDs. Failed requests are invalidated for explicit retry. A measured curved connector joins the selected category and actual proposal card. The server checks generation/revision currentness. Empty or partial pages say what is missing; a link never authorizes a job. Review opens the displayed recorded proposal.
- Home: loaded-record statistics with explicit definitions, a real next action, a bounded current knowledge preview, readiness/decision bars and vertical source-to-proposal/run links. A merge is separate from benefit. Unknown is separate from zero. Exact whole-library totals and trends are not claimed.
- Projects: selected projects and existing proposals lead. Context/connection setup, broad reviewed scans and evidence exploration remain reachable through disclosures. The proposal trail derives saved post, review, immutable plan, run and PR states from returned records. Its labels grant no additional authority.
- Account: profile/sign-out, appearance, existing motion preference, Connections, Usage/Billing, Inbox, Privacy and other existing workflow destinations. Navigation preferences contain only representation and topic IDs, scoped by workspace and library space. Clear those preferences on explicit sign-out and workspace access loss; preserve unrelated configuration.
- Motion: use Motion for React for a short branch reveal and capture opening. Keyboard actions remain immediate. Device reduced motion and the existing interface-motion switch suppress it. CSS transitions name their properties. No layout physics, auto-panning, viewport reentry choreography or inference is required to browse.
- Reads: debounce topic search, refresh on entry/focus/visibility, fence obsolete responses, keep existing cursor bounds and avoid recurring browse polling. Home preview is one bounded topic page, not a customer-table scan. Project evidence reads remain disabled while its disclosure is closed. Provider billing is not inferred from smaller payloads.

## Verification boundary

The implementation must preserve existing role, owner, source-version, grant, correction, cost-reservation, executor, plan/patch/publication and provider checks. ADR 096 authorizes additive category metadata/indexes and bounded explicit organization writes; it authorizes no grant broadening, provider fallback or paid job. Fixed Basic queued Vercel builds remain required.

Local labeled fixtures establish render/state behavior only. Record real staging, exact CI and canonical production evidence separately. A screenshot cannot establish animation smoothness, physical-device usability, independent comprehension, cost settlement or full V1 acceptance. New-user and external gates remain pending when unavailable.
