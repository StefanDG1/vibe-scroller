## Pricing language

Starter monthly: "EUR 19, billed monthly." Annual: "EUR 190 billed once per year, equivalent to EUR 15.83 per month." Weekly: "EUR 5.99 every 7 days." Pro follows its own values in the billing catalogue.

Show consumer tax-inclusive payable prices when required. Never show an annual monthly equivalent as if it were charged monthly. The annual discount relative to twelve monthly payments is about 16.7% for both tiers. Recompute copy from actual price configuration.

Processing-credit quotes appear before work starts. Explain that videos and coding tasks consume different amounts. Illustrative clip counts must be labeled estimates and benchmarked before publication.

The platform subscription pays for hosted organization, storage within quota, and its stated processing allowance. A connected ChatGPT plan or API key has separate terms and limits. Customer API billing is not included merely because the platform subscription is active.

## FAQ answers

**Does it make me install an application?** No. The library, dashboard, proposals, and approvals work in the browser. A paired local runner is optional for executing code on your computer. Cloud execution is separately metered.

**Can it read every saved Instagram video automatically?** Not as a guaranteed launch capability. Share a supported link, import links, or upload a permitted file. Automatic account import is enabled only for verified supported connections.

**What happens if an idea does not fit my project?** It stays in your library with the reason. VibeScroller does not need to turn every video into a change.

**Does a merged PR mean the idea worked?** No. The dashboard tracks merge status and measured outcomes separately.

**Can I use my ChatGPT subscription?** Supported local Codex sessions can use your own eligible account. General hosted inference depends on a separately supported integration. The app shows the funding route before execution.

**Are my videos public?** No. Imported content and project context are private to your workspace. Temporary originals expire under the retention policy. Connected providers may process the data needed for your task.

**Will it create a whole business for me?** That is a future product direction, not a V1 subscription feature.

## Visual system

Use a calm, dense-enough work interface rather than a landing-page-only aesthetic. Derive accessible components from CompanyNerve and choose one consistent recipe. Use Inter or a system sans-serif for interface text and a monospace face for code. Do not ship font files from this handoff.

Proposed tokens: deep ink text `#17252B`, light canvas `#F7FAFC`, white panels, primary teal `#0E7490`, subtle borders `#D9E3E8`. Validate every foreground/background pair before use. Status must use text and icons, not color alone.

Use modest corner radii, consistent spacing, restrained motion, and readable summaries. Support light and dark themes through semantic tokens. Never invert screenshots or source images to create dark mode.

## SEO and analytics

Public pages have unique titles, descriptions, canonical URLs, Open Graph metadata, robots rules, and a sitemap. Private application routes are noindex and absent from the public sitemap. A robots rule is not access control.

Use truthful SoftwareApplication structured data without invented ratings, reviews, or price availability. Generate pricing markup from the same catalogue used by checkout.

Do not turn private videos, transcripts, or repository insights into indexed SEO pages. Public examples need separate rights and an explicit publication process. Domain migration later requires canonical updates, redirects, callback updates, and private-session testing.

Use privacy-minimized product events. No session replay by default. Marketing tracking remains disabled until the relevant consent configuration and policy are implemented.
