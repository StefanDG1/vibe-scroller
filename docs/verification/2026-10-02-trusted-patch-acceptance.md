# Synthetic trusted-patch acceptance

This document describes the requirements for synthetic production trusted-patch acceptance. The following conditions must be met:

* Private evidence must require authenticated workspace membership.
* Source deletion must block access before queued storage cleanup.
* Workspace export must include saved records and exclude credentials.
* Synthetic production verification does not establish completed V1 acceptance.

This exercise is an explicitly labeled synthetic acceptance exercise. The current controls are available and must be followed.
