# Metered Google EU inference

Mode: reference. Decision date: October 3, 2026. Implements the owner-authorized Google-credit route without pooling a personal subscription. WP10, WP12, WP16 and WP17 apply.

The dedicated vibescroller-inference-2026 project uses the existing billing credits. The owner authorized unlinking only vydero when the billing account reached its linked-project limit. This disabled billing-backed services for that project without deleting it; Exponential and vydero-media-staging remained linked.

The reviewed model is gemini-3.5-flash-lite, GA, through the EU multi-region endpoint aiplatform.eu.rep.googleapis.com. Standard EU PayGo prices reviewed October 3 are USD 0.33/M input tokens for text, audio and images, and USD 2.75/M output including thinking. The internal ceiling uses a conservative 1.5 EUR/USD provision for exchange/tax variation. It is an estimate, not a provider invoice or a promise that credits make usage free. A processing credit covers EUR 0.01 of this provision. Round media inference once at the job boundary, adding separately measured sandbox compute.

The non-resetting operator budget google-eu-pilot-2026-10-03 has an immutable EUR 10 ceiling. Holds and settled usage share that ceiling atomically. Unknown usage keeps the full hold; no timed release or retry assumes zero cost. An exhausted budget pauses work. Increasing or replacing this ceiling needs an explicit reviewed deployment, not a daily reset. The configured pricing/data review expiry and kill/recovery switches disable new requests.

Production uses Vercel OIDC, Google STS and short-lived service-account impersonation. The pool accepts only the exact VibeScroller production project/team subject and audience. Its custom role contains only aiplatform.endpoints.predict. There is no JSON service-account key and no credential returned to Convex or a browser. The broker executes generation itself. A separate HMAC binds purpose, time, reservation key, payload digest and maximum cost. The public consume mutation cannot create a hold; it atomically consumes only a matching existing internal reservation, once. Payloads are capped below Vercel's request limit; the database receives only a small authorization envelope, not raw media.

Count tokens before generation and reserve schema overhead plus the entire output maximum. Refuse generation if that quote exceeds the job's remaining allowance. Generation has no tools, URL context, grounding or explicit cache. Only bounded inline JPEG/MP3 and text parts are supported. Thinking uses MINIMAL; no ignored sampling parameters or priority tariff is selected. Measured usage includes thinking, refuses unexpected traffic and settles even when a returned result is incomplete. Missing usage retains its reservation. Strict application schemas and evidence authorization still apply after the provider result.

The Google media route uses isolated FFmpeg preparation at 32 kbit/s MP3 so ten minutes fits the broker request bound, automatic speech transcription and up to sixteen selected frames. Frame batches stay below the request limit. Timestamp estimates are disclosed; this is not forced alignment or exhaustive frame coverage. The personal OpenAI route and existing free Workers route remain explicit alternatives, never automatic fallbacks. The selected route and pipeline hash bind reusable media stages. Reusing a metered stage does not release an earlier final-generation hold whose cost is uncertain.

Google's commercial Cloud processing terms, applicable transfer safeguards and actual regional processing need publication review. No model-training or zero-retention claim follows from a regional endpoint. Provider defaults can include abuse monitoring and implicit in-memory caching; neither grounding nor explicit context caching is requested here.

Initial owned provider check succeeded in EU with 80 input and 5 output tokens using operator CLI authentication. That check does not verify production federation or customer media. Tests, production identity, actual speech/image analysis, tariff and final release evidence are recorded separately in [the implementation record](../implementation-status.md). Keep public media and live checkout release switches off until the complete acceptance passes.

Actual audio generation rejected the full strict schema with HTTP 400, while the identical owned audio and model succeeded with structural fields only. The adapter now supplies types, required properties, enums and nested item/property shapes to Google; bounded lengths, numeric ranges and exact evidence records remain in the full contract and strict application validation. This lowers the provider decoder grammar, not the authorization or evidence contract. Speech warnings are bounded to the existing 500-character output limit. Safe broker diagnostics record only a category and provider HTTP status, never response bodies, prompts or credentials. Pipeline v1.5 invalidates earlier media extraction hashes. See the [official schema complexity guidance](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/control-generated-output).

Pipeline v1.6 preserves original speech language, model and uncertainty alongside corrections. Successful source generations receive a strict processing receipt bound to the generation, actual queue start and settled allowance: measured tokens including thinking, conservative inference estimate, compute credits, elapsed time and reused extraction. The private detail screen exposes these facts in compact expandable controls. Operator reservations retain settled micro-units for reconciliation. Deletion and replacement clear content-bearing provenance; unknown-cost failures never receive a successful receipt. Historical sources without measurements are not backfilled with invented costs.
