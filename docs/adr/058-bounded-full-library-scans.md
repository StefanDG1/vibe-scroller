# ADR 058: Bounded scans of saved links across selected projects

Status: accepted implementation direction. Date: October 5, 2026.

The owner requested all currently saved, available and unanalyzed links to be processed, their knowledge compared with selected repositories, and detailed issues drafted for another AI agent to investigate. The owner requested at least ten repositories for the verified personal administrator account, including Kinetexa, stefan-career and CompanyNerve. Existing profiles, manual corrections, provider restrictions and spending limits remain authoritative.

A scan first inventories every page without inference. Approval binds the current source cutoff, selected repository snapshots and confirmed profile versions, funding route and maximum credits. It reuses completed analyses, skips unavailable links, and visits every surviving topic evidence page for each selected repository. It preserves no-fit and already-implemented results. Useful results become app issue drafts through the existing issue builder. Publication, coding, merging and deployment retain separate authorizations.

An own-plan scan also requires fresh authentication and explicit permission for the user's paired device, advertised model, reasoning effort and account binding. This grant expires after 24 hours and covers only links saved before its cutoff. Every dispatch repeats membership, device, model and source checks. It cannot authorize another account, future captures, model substitution or paid inference fallback. Media preparation and repository evaluations retain their existing separately disclosed credit charges. Unknown usage remains reserved and blocks retry.

GPT-6.1 Sol supports low and medium reasoning in the official model documentation. On October 5 the updated official Codex CLI 0.160.0 advertised it in the signed-in account's model/list response. The separate documented public Responses adapter used by the paired analysis runner still advertised older models. Windows restricted-read isolation probes refused execution; the app must not combine these catalogs or enable unrestricted execution to claim GPT-6.1 analysis. The UI advertises the actual executing adapter's catalog. Text/image model support does not imply direct audio/video decoding.

The personal repository override applies only to allowlisted verified subjects and does not change commercial Starter or Pro entitlements. Whole eligible repository discovery remains the default; secret exclusions, bounded excerpts and explicit coverage remain necessary. No folder selection is required.

Affected acceptance: full-library pagination, source cutoff, workspace isolation, manual exclusions, late evidence pages, stale source/profile/repository versions, canceled grants, account/model changes, inaccessible links, unknown cost, spending ceilings, duplicate delivery, per-repository useful/no-fit results, source and repository proof in drafts, and mobile controls. Live provider and production acceptance must be recorded separately in the implementation ledger.

The implementation is covered by local regression and builds; live acceptance remains separate in the implementation ledger. This ADR does not establish commercial subscription access or complete the original W01–W07 external gates.
