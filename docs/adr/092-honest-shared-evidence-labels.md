# Honest shared evidence labels

Mode: reference. Decision October 8, 2026. Status: implementation candidate.

A real two-account production sharing check exposed a null `user_note` timestamp rendered as `0.0s`. JavaScript converted null to zero. The shared route also fell through to the plan-review heading.

Shared references now show seconds only for a finite, nonnegative numeric timestamp. Genuine zero remains zero; an untimed reference keeps its evidence kind. The shared route uses Shared knowledge in both the workspace header and page heading. Existing studio styling, protected citations, pagination, grants, corrections and funding authority are unchanged. No extra backend read or inference is introduced.

The regression covers the actual null note reference, missing timestamps, genuine zero, a timed frame and invalid numeric times. The two-owner-account grant test establishes cited user-note retrieval, continued private denial, fresh-sign-in refusal/recovery and revoked-detail denial at its tested scope. It does not establish mixed-evidence retrieval, natural expiry, independent comprehension or complete V1 acceptance. Exact failures, commands, commits and serving evidence belong in implementation status.
