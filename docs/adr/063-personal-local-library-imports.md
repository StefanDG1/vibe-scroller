# Import an explicitly bounded personal subscription library run

Mode: reference. Decision October 6, 2026. Status: implemented with local enforcement tests; production acceptance remains in the execution ledger.

The owner authorized reanalysis of all genuine saved posts, local preparation/offline transcription, GPT-6.1 Sol Medium using their own subscription, shared knowledge and useful issues for five selected repositories. The owner separately approved a temporary session lasting at most four hours. This supersedes ADR 059's comparison-only boundary for this allowlisted personal workflow. It does not enable general commercial hosted subscription inference, pool an account, authorize paid fallback, consume reset credits, or approve new exact issue bodies.

Reuse canonical sources, private EU evidence assets, knowledge memberships/jobs/evaluations and the existing issue publisher. An owner/admin with fresh authentication approves an actor-bound four-hour workspace run covering at most 200 exact existing sources, 20 selected confirmed repositories and 1,000 preparation jobs. Later captures and unselected repositories are outside that grant. Every import checks current source generation, revision, rights, membership and content hash. The official-client output is untrusted and independently validated. Receipt hashes use canonical JSON so transport key order cannot change their meaning. Operator receipts document a tested own-account client, not a cryptographic provider attestation.

Local decoded frames are bounded private uploads, verified against approved byte counts/SHA-256 and actual storage metadata. The database replaces local filenames with the verified owned asset IDs. Transcript references remain timestamped; frames are samples. The browser never receives local credentials. Original text and manual corrections remain retained. Stable insight IDs used by manual memberships/exclusions must survive; otherwise the import stops for reconciliation. Replacement occurs atomically after validation, leaving the existing ready analysis available during preparation. Current revision checks fence later synthesis/evaluation and deletion cannot restore source content. Source deletion redacts pending local input content; workspace deletion purges the new records and evidence through existing deletion machinery.

Source imports classify existing insights without dispatching metered synthesis. Local summary/evaluation jobs use a separate local-prepared state and reuse existing bounded contracts, pagination and current-input checks. Trusted repository retrieval records pinned inspected windows; returned citations must fall within them. No credit reservation is created or settled by this route, and unrelated unknown holds remain untouched. The existing paid organization policy stays separate. No-fit, unsupported and already-implemented outcomes remain valid. Exact reviewed publication, visibility/privacy and GitHub permission checks still precede external issues; coding and merge authority do not follow from analysis.

A chosen evaluation group contains at most twelve distinct included insight memberships from the granted sources. Bind all involved topic versions, source revisions and the current repository/profile/preference versions. An exclusion or regrouping in any included topic invalidates the result. A selected group explicitly omits the rest of the corpus; an initial all-page discovery pass does not turn a bounded repository inspection into a whole-code review. Include current rejected/deferred judgments in later prompts. Expired/canceled runs redact unfinished transcript staging and retire unused uploaded frames; finished canonical evidence follows source/workspace deletion and export boundaries.

The ordinary acquisition/trial broker retains 64 connections and 300 MB. The explicitly selected personal-library launcher uses the same exact three OpenAI destinations, public-DNS/IP pinning, port 443, four active connections, 300-second absolute connection and 180-second idle bounds, with at most 2,048 connections and 2 GB for the longer finite batch. Model children still cannot read authentication files, write, access the broker or use a network. Credentials remain in VM tmpfs. Turn deadlines, one claimed application attempt and unknown-result reconciliation remain enforced. No device code is written to a file.

Media preparation exposed a real rounded-end failure: FFmpeg can exit successfully without producing a requested terminal JPEG. Both decoders must list only existing nonempty image files and derive coverage from actual outputs. Failed preparation is retained as evidence and retried only after this concrete correction; no absent image is presented as analyzed.

Affected verification includes actual missing-frame reproduction, decoder manifests, broker limits and child probes; tenant/role/revocation/expiry fences; receipt/reference/citation validation; manual corrections and deletion; no metered dispatch or credit change; all-page synthesis/evaluation; app issue review and actual publication; mobile/desktop UI; production deployment/version. Unit fixtures establish enforcement, not model quality, customer benefit, complete external acceptance or physical Android use.
