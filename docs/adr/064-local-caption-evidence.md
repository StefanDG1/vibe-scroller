# Import recovered captions with personal source evidence

Mode: reference. Decision October 6, 2026. Status: implementation candidate.

A real personal-library review found that the isolated downloader recovered captions that were absent from the app source. The operator analysis incorrectly read only the app acquisition description. A caption-only product idea was consequently omitted even though its permitted local fetch had recovered the text. This is an evidence-input defect, not a reason to accept unsupported title citations.

Extend [ADR 063](063-personal-local-library-imports.md) through the existing acquisition manifest contract. Personal source preparation may include bounded metadata from a supported permitted public source fetch. Validate the pinned downloader version, successful acquisition state, byte/duration bounds, credential refusal and current source URL policy. Bind it to the same actor, workspace, rights attestation, generation, revision and source fingerprint as the prepared speech and frames. A replay with different acquisition metadata is stale.

Only an included nonempty caption permits the exact caption evidence reference. A completed canonical import retains its validated acquisition description and actual import timestamp without renaming the saved post. Preserve owner text corrections. Completion, expiry, cancellation and source deletion clear temporary acquisition staging; exports omit this second raw metadata copy. Existing canonical source deletion removes acquisition content.

Local model input must include the actual recovered caption. Use every available slide frame for a carousel rather than silently omit slides through video sampling. Preserve earlier limited outputs and failed receipts as superseded private evidence. Reprocess against current source revisions and an explicitly authorized personal run; do not overwrite stale evidence, invent absent captions or reset metered holds.

Verification covers caption references, missing and forged metadata, replay changes, bounds, canonical source persistence, title preservation and staging/export redaction. The full checks and actual production corpus/import/repository outcomes are recorded separately. No paid fallback, model change, expanded provider destination, publication permission or hosting-policy change follows from this correction.
