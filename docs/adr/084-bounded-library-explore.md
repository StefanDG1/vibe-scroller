# Explore current knowledge through bounded evidence views

Mode: reference. Decision October 7, 2026. Status: implementation candidate; exact release and real-library browser acceptance pending.

Library Explore reuses canonical topic memberships, exact-reference synthesis, evaluations, issue drafts, improvement runs and outcomes. Topic tree is the initial readable representation. Connections offers the same bounded cited groups as a native list or an intentional canvas. Idea journey shows recorded source, evaluation, draft/publication, run, PR/deployment and outcome facts. Topic overview compares current permitted page counts and explains overlapping membership. What helped separates recorded judgments from reported comparisons, including inconclusive and unmeasured results. No inference, funding reservation or permission follows from browsing or changing representation.

Each query recomputes ordinary account/workspace authorization. Shared workspaces use their existing authorized scope. Owner-private libraries default to the first stated focus or Personal; Business is a separate view. Connected spaces requires the current confirmed combined-browsing setting. Every cited input of a summary, evaluation or outcome must be current, rights-attested and filed within the selected space. A mixed summary is withheld in a single-space view. Disconnect, correction, deletion, rights loss and recovery deny later retrieval. Team and assistant grants remain separate; this interface provides no recipient or MCP authority.

Pages inspect at most ten topics, the first twenty memberships per listed topic, twenty memberships in one selected branch, ten evaluations with at most five issue drafts each, or twenty recorded outcomes. Topic-list version checks and counts use existing atomic dashboard metadata and require its completed migration. Missing metadata yields an updating view without loading full analyses or transcripts. Selected branches read canonical evidence; reused synthesis jobs must cite only current inputs in that branch page. Counts describe those current permitted pages and never claim full-library coverage. Unknown or unreturned parents remain roots on the current page. The browser keeps at most forty loaded topics and offers next and first-page controls. A connection page has at most forty visible ideas/group nodes and separate group pagination. Only cited group-to-input lines are drawn; no all-pairs comparison or causal edge is invented. Layout is stable and local. Existing visibility/online-aware polling stops hidden work, backs off on failure and fences late responses.

Manual parent topics and up to eight normalized aliases use a separate layout version with compare-and-swap, same-workspace parents, cycle rejection and a twelve-level bound. These changes leave source generations, semantic topic versions, evidence, budgets and analysis unchanged. Alias search uses an additive indexed search projection. Its resumable ten-topic backfill fills only absent fields and preserves concurrent manual corrections. Existing automatic classification and topic rename initialize/update that projection. Existing merge/split and manual exclusions remain authoritative.

The native evidence dialog supports keyboard dismissal and returns focus to its originating node. Phone canvas evidence uses a bottom sheet; the readable list completes the same task without dragging or zoom. Published/private evidence links use existing protected source routes. A source must remain authorized when its full detail opens. Journey history distinguishes current repository fit from historical fit and does not equate merged, deployed or accepted with benefit.

Affected checks: tests/knowledge-explore.test.ts, tests/topic-tree.test.ts, tests/knowledge-map.test.ts and recorded journey/outcome cases in tests/knowledge-library.test.ts; full formatting, lint, types, unit/auth/Python tests, both production builds, audit and secret scan; native synthetic phone/tablet/desktop captures and independent finish review. Real source recall, held-out relation judgments, independent comprehension and measured usefulness remain separate acceptance. F019 updates all four foundational briefs together without a new price, provider, marketing or customer-value claim.
