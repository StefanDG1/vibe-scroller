# ADR 031: public link retrieval and private previews

Status: real anonymous Instagram audio and visual preparation passed; production account analysis acceptance is recorded separately. Date: October 2, 2026.

A newer owner post played in Instagram but the production retriever failed. An independent worker showed yt-dlp's one-download stop code with no metadata output. Removing that limit from the metadata-only invocation exposed valid video formats and an absent duration. Another saved link exposed separate video and audio representations: the previous combined-format selection fell back to audio and produced no visual evidence. These are application defects, not evidence that all saved posts are private or require sign-in.

Keep the reviewed yt-dlp 2026.08.19 release and isolation boundary. Apply the one-download limit to each actual transport invocation, accept its stop code only when the exact expected file exists, and bound the aggregate input bytes. Metadata may omit duration. Record the intermediate state as downloaded, then disable source networking before probing, combining separate streams and decoding. Only the measured decoder result can promote transport to acquired. A measured duration above ten minutes, excessive dimensions, malformed input or incomplete decode stops analysis. Separate streams are combined inside the network-disabled microVM with file-only protocols and fixed stream maps. No remote postprocessor, browser cookie, login restriction bypass or alternate inference provider is introduced.

The real second link passed anonymous preparation: 34.804 seconds, 1,114,636 PCM bytes, 22 sampled visual frames and full_sampled coverage. This verifies retrieval and preparation for that post; it does not verify its summary, every Instagram post or the complete V1 benchmark. The metadata-limit diagnostic, unsupported-duration result and two audio-only assertion failures remain in private logs. Eight probes with an older local downloader reported authentication refusal; they do not override the successful pinned production-worker observation. See [the coarse evidence](../../infra/public-link-preparation-proof.json).

When LINK_PREVIEWS_ENABLED is true, importing or saving a new link queues an independent metadata/thumbnail attempt. It does not start inference or consume AI allowance. Fetch only canonical supported post pages and reviewed image CDNs. Resolve and pin public addresses, revalidate every redirect, keep TLS verification, bound headers/time/body, require a matching post identity, and accept only bounded JPEG bytes. Do not forward cookies, preserve signed image URLs or hotlink creator images. Store thumbnails as tenant-scoped private assets served by the existing authenticated evidence route. Missing metadata retains a neutral placeholder. Prepared visual evidence also supplies a thumbnail while analysis continues. Initial direct HTML attempts for three newer Instagram links were unavailable; do not claim they produced thumbnails before preparation.

Preview completion is bound to the original post identity rather than the analysis generation, so approving analysis does not invalidate an in-flight thumbnail. Deletion or changed identity blocks late restoration and queues orphan removal. Existing storage quotas apply. SOURCE deletion clears the preview and all its assets. Account exports preserve the private source association. Release this metadata capability independently of commercial inference gates.

Analysis quality reviews are optional, private per reviewer and bound to the exact generation and analysis hash. Changed results cannot inherit an earlier verdict. Duplicate submissions are idempotent; edits preserve history, notes reject credentials, and source deletion removes those notes. A review never fabricates measured benefit or changes a cost reservation. Prepare the owner's five requested examples without filling human judgments on their behalf.

Deployment operators can temporarily enable OWNER_QUALITY_REVIEW_CREDITS_ENABLED to grant at most 100 expiring, idempotent free acceptance credits to a currently approved personal-alpha workspace owner. These are operator-funded quality testing allowances, with an audit entry and no invoice, purchased balance or Stripe payment claim. Disable the grant gate after the explicit bounded grant. Customer payment and public launch gates remain separate.

Relevant upstream documentation: [yt-dlp download limits, JSON output and format selection](https://github.com/yt-dlp/yt-dlp), [Node HTTPS certificate and request controls](https://nodejs.org/api/https.html), [Node DNS lookup](https://nodejs.org/api/dns.html).

The initial anonymous HTML preview failures were traced to Instagram canonical URLs containing the creator username. Matching the validated shortcode across those canonical paths produced three real JPEG previews (40,181, 30,702 and 25,705 bytes) without credentials. Production preview work runs asynchronously through the existing workflow pool with two concurrent workers. On October 2, the feature was enabled and 104 existing owner links were queued through a bounded, owner-scoped internal backfill. These are attempts, not a guarantee that every platform supplies a thumbnail.

Normalized PCM can end a few milliseconds after the measured video duration. Personal transcript validation retains the audio digest and one-second duration tolerance, rejects segments beyond the actual audio or starting outside the video, and clips a bounded terminal overrun to video EOF with an explicit warning. The original fabricated-timing rejection test remains; a separate PCM-rounding regression test verifies this correction.
