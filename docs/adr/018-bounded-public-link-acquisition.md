# Bounded public-link acquisition

Mode: explanation. Decision: October 2, 2026.

Imported links must enter the audiovisual pipeline without requiring a supplied transcript. A saved URL alone does not prove media access. The personal alpha offers explicit per-source or five-source batch approval using an online, owned device and an account-advertised ChatGPT model. Each video independently reserves ten compute credits. Planning and coding approval are unaffected.

The acquisition worker uses the separately pinned E2B image in `infra/e2b-acquisition-build.json` and checksum-verified yt-dlp release in `infra/downloader.json`. Supported single-post identifiers determine the allowed public network domains. Independent kernel rules block private addresses, metadata and control services. The worker runs without provider credentials, plugins or login cookies, with bounded subprocess output, bytes, time and memory. Source acquisition cannot override platform authentication, paywalls, CAPTCHA or DRM. Decoder network access is disabled after retrieval.

Only minimal post metadata, transcription and selected private evidence survive the temporary worker. The Instagram archive is parsed on the selecting device and never enters this worker. Source titles and captions remain untrusted data. Caption evidence is labeled separately from speech and sampled frames. Cancellation, deletion, membership, device and generation checks fence publication; uncertain termination retains the compute reservation.

Worker preparation shares the existing durable workpool, limited to two concurrent actions, with retries disabled for external effects. Import batches that enable personal analysis contain up to five sources, with an explicit maximum of fifty compute credits. Larger imports can be saved without analysis or submitted in reviewed batches. Already queued or ready sources are not charged again.

The verified image and worker tests establish isolation and resource behavior. They do not establish reliable Instagram access. A supplied Reel returned HTTP 429 from the cloud network; another supplied item was an unsupported carousel. The existing four production analyses used previously attached permitted media. Their success does not make this new downloader or carousel acquisition universally successful. The normal browser library remains usable when retrieval or the optional laptop is unavailable.

Affected tests: acquisition policy/manifests, Linux acquisition worker boundaries, personal batch authorization/evidence/deletion, isolated egress and offline decoder tests, and actual staging source processing. `ACQUISITION_VERIFIED` may be enabled only with matching pinned-image evidence. Commercial ChatGPT-plan access remains a separate external gate.
