# ADR 032: collections, whole-post scope and dense private evidence

Status: implemented; production observations are recorded separately. Date: October 3, 2026.

The owner found the real analyses broadly useful but reported an intrusive native phone picker, single-point project selection, weak library navigation and too few samples for fast edits. Treat that feedback as one operator observation, not five completed accuracy verdicts or market validation.

Use reviewed broad collections (Business, Coding, Design, Media & music, Food, Fashion, Health & fitness, Lifestyle, Learning, Other) above workspace-specific topics. Validated analysis creates specific topics; a meaningful Subject / Subtopic label supplies at most two suggested topic levels without adding compulsory nested navigation. Broad collections derive from explicit subject labels and aliases, never an unrelated creator name or video format. A post can belong to up to three broad collections and eight specific topics. Manual topic overrides survive reanalysis. An unknown subject stays in Other until a meaningful subject is supplied. Shared vocabulary still requires explicit name-only suggestion and operator review; private sources never become cross-tenant training data.

All posts, Analyzed, Not analyzed and Processing are independent library filters. Indexed sorting distinguishes app creation time, supplied platform save time, verified original publication time, update time and title. Search stays relevance-ordered. Unknown publication dates are displayed honestly and appear last. Accept a bounded original timestamp from the isolated downloader or matching canonical page metadata; never substitute an import timestamp. Materialized category memberships retain the same date fields and tenant checks before joining source records. Migration reuses saved analyses without inference.

Default both the business-profile shortlist and technical match to every main point. Advanced checkboxes allow exclusions. Validate nonempty, unique existing insight IDs; canonicalize to analysis order. Bind exclusions into semantic cache keys and persist the technical scope in matching jobs. Proposal commit rejects excluded insight IDs and source evidence even if a model includes them. A whole-post request still permits an honest no-fit outcome and does not grant coding approval.

Use existing Radix radio menus for consistent dark selection, keyboard navigation, focus restoration and 44-pixel touch targets. Evidence citations and gallery frames open an authenticated native dialog, with Escape, close, previous/next and restored focus. The original-post thumbnail card retains the owner's separately requested external link. Private image requests and deletion protections are unchanged.

For short videos up to 90 seconds, examine four small candidate images per second; through five minutes use two, and longer clips use one. Bound candidate decoding to 600 small images and retained full-size samples to 48. Preserve periodic/end samples and prioritize visible changes. Personal-plan analysis receives the bounded samples; its image byte ceiling remains 12 MB. The hosted free-model route retains its separately verified four-observation pass and hard daily reservations. Do not claim exhaustive visual coverage or silently increase free-provider budgets. The detail view initially shows cited frames, at most eight, or four samples when no frame is cited; the remaining frames are optional.

Defer comparative quality, usefulness and truth-ranking scores to V1.1 until calibrated against human judgments. Existing evidence, uncertainty and optional reviews remain available without a fabricated numerical truth score.

The dedicated GitHub App was made public for native customer installation and renamed VibeScroller. Its App ID, OAuth callback and webhook stay intact. GitHub supplies All repositories / Only select repositories; application context and coding still require workspace-authorized, confirmed projects. This work did not modify the owner's installation selector. Commercial execution, checkout and legal release gates are separate from public App installability.

The real rapid-cut Reel decoder test returned 48 frames, normalized speech and an actual publication timestamp in 104 compute seconds, without browser cookies, supplied media/transcript or inference. Commands, prior failed checks and final production evidence are in [implementation status](../implementation-status.md). The official [Sandbox pricing](https://vercel.com/docs/vercel-sandbox/pricing) separates active CPU, memory, transfer and snapshot storage; app credits and reservations are not provider invoices.
