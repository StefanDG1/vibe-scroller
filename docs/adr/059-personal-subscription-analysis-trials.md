# ADR 059: Personal subscription analysis trials

Status: accepted personal experiment direction. Date: October 5, 2026.

The owner requested laptop preparation and a private Codex cloud trial using their own subscription, before incurring further managed media fees. These experiments remain allowlisted, actor-owned and separate from commercial hosted inference. They cannot pool a founder subscription, upload OAuth credentials, invoke a paid API fallback, overwrite reviewed source analyses or authorize publication/coding.

Reuse the current acquisition policy, verified downloader, decoder, PCM checks, offline Whisper adapter, insight contract and official Codex app-server. Docker Desktop supplies a local Linux VM boundary for personal preparation. The untrusted worker has no host bind mounts or daemon socket, no direct network, a read-only root, dropped capabilities, no privilege escalation and bounded resources. A separate credential-free HTTPS broker allows only source-policy domains and public DNS addresses. Stop it before decoding. The verified standalone downloader needs a bounded executable VM-local temporary mount to unpack its shared libraries; this grants no host access. Files, transcripts and sampled frames stay in the ignored private directory.

The Windows official-client restricted-read profile refused execution. A separately installed official Linux client can use a fresh, user-approved session inside Docker. Do not copy the Windows OAuth cache. Its model children use the official read-only permission profile, with explicit credential-file and broker-socket denial, inside a container that contains no host repository or private host files. Disable external apps, plugins, browsers, web search and model shell tools. Probe the real child boundary again with authenticated state before inference; failure blocks the trial. Model availability and effort must come from that executing client's own model/list response, and account changes, model rerouting, unexpected tools or incomplete turns reject the result. Own-subscription allowance and one attempt per selected post replace app processing charges for this experiment; there is no funding substitution.

The first app comparisons export only already-prepared text from one to five selected posts. They exclude video frames and explicitly downgrade coverage to audio-only or caption-only. An aggregate transcript cannot establish a quotation at a particular segment time. Preserve this warning in every returned result. The separate local media-preparation command can produce fresh normalized audio and sampled frames, but does not mark an app post analyzed or close the full-library scan.

A trial binds actor, workspace, source generation/content hash, exact input bundle, requested model/effort/route and a 24-hour expiry. Prepare requires fresh authentication, rights and own-plan permission. Import validates the existing insight schema, source identity, coverage and exact evidence references. It returns a comparison for owner review rather than replacing canonical analysis. The requested route in an imported record is not independent provider attestation. Keep real executor evidence separately in the implementation ledger. Cancel/expiry erase server-side trial text/results, deletion schedules redaction, and reads/exports hide stale or deleted material immediately.

Codex cloud is a private user-operated environment with only the selected VibeScroller repository, no production credentials and no additional network domains. The owner authorizes transfer of selected evidence to their own private task, not publication to GitHub. Native task creation, account permissions and usage remain controlled by Codex. Manual copy/import does not establish unattended dispatch, a provider-enforced cloud time budget or a commercial subscription-funded service.

Affected acceptance: account/tenant isolation, fresh permission, stale corrections/deletion, expired/canceled grants, input/result bounds and hashes, unsupported sources/models, real Docker network/file/credential boundaries, authenticated model completion, private cloud task/results, zero app reservation for text comparisons, mobile copy/import/review and unchanged fixed Basic hosting. Record passes and missing approval separately; none of this closes the original V1 external acceptance gates by implication.
