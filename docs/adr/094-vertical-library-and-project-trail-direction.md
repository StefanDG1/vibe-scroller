# Vertical library and project trail direction

Mode: reference. Decision date: October 8, 2026. Status: owner-selected planning direction; not implemented.

## Decision

The owner selected design 2's vertical knowledge atlas for Library and design 3's source-to-proposal trail for Projects, rejected design 1's collection desk, and requested five mobile controls with Save centered. Future mobile order is Home, Library, Save, Projects, Account. Account contains profile, Connections, Usage/Billing and privacy controls; inbox/notifications remain reachable. Save opens capture rather than becoming a selected navigation destination.

The [UI and UX plan](../design/VIBESCROLL-UI-UX-PLAN-20261008.md) develops these constraints with additional illustrative refinements. The owner subsequently confirmed overview first, remembered valid scope/branch/position on return, and a theme following the device light/dark setting. An optional Account override may provide System, Light and Dark. Detailed compositions remain open for review. This decision supersedes the older four-destination mobile structure only for the future redesign. It does not change the current production UI or rewrite ADR 093's dated acceptance.

## Boundaries and validation

Preserve private ownership, source/insight versions, manual taxonomy choices, explicit combined scope, grants, exact work/publication approval, budgets and provider restrictions. Deterministic layout must not start inference. Friendly proposal language does not publish a GitHub issue or authorize coding.

No runtime design contract, schema migration, application implementation, provider action or deployment follows from this documentation decision. Required implementation tests cover navigation/capture recovery, bounded hierarchy and counts, provenance/currentness, scope/role denial, state-correct proposal actions, keyboard/touch behavior and exact release evidence. Independent and external acceptance remains separate.
