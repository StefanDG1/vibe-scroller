# ADR 099: Readable card labels and topic controls

Status: accepted owner direction, October 9, 2026. Release evidence is separate.

## Decision

Multiword category names may wrap at word boundaries in taller cards, superseding ADR098's one-line rule for those labels. Single-word labels keep ellipsis rather than splitting a word. Preserve ordered rows, card widths, accessible full names, measured connectors, existing branch motion and fixed navigation. Show stored descriptive insight titles without the two-line clamp; rows grow naturally, while full original claims remain available on tap.

Move the version-bound topic-parent form into Library options. Name the selected topic in the Move disclosure, label its destination Parent category and its action Move topic. This moves the topic in the filing tree and grants no access, runs no analysis and changes no evidence.

Replace the prominent Next categories page control with the lower-emphasis Show more topics action and a disabled Loading topics state. Keep explicit bounded cursor loading and the existing forty-node hierarchy limit. This is necessary to make later permitted topics reachable without fetching the whole library; it is not automatic paging or per-card backend work. More insights remains the separate selected-topic evidence control.

## Verification

Check category word-boundary wrapping, intact single-word labels, complete insight titles, no viewport overflow, measured branches, stationary navigation and hidden-but-reachable topic organization. Distinguish synthetic local presentation checks from real canonical production and writes. No new analysis or production categorization write is required for this visual correction.
